# Airspace, Equipment, and VFR Weather Minimums

**Episode:** 16
**Version:** 0.1.14

## In this episode

One fictional daytime cross-country turns airspace into a repeatable decision: locate the airplane in three dimensions, establish the communication or clearance required for entry, match the pilot and equipment to the full route, and apply the correct VFR visibility and cloud minimums. The route climbs from Class Golf airspace into Class Echo airspace, passes near Class Charlie airspace and beneath a Class Bravo shelf inside its Mode C veil, and approaches a Class Delta destination. Lowering weather, special use airspace, an MTR, and a TFR test the plan and clarify which rules belong to each category.
