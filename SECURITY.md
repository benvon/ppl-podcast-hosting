# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability.
Email [feedback@pplstudyguide.com](mailto:feedback@pplstudyguide.com) with a
concise description, affected files or workflow, steps to reproduce, and the
potential impact. We will acknowledge the report within seven days and provide
status updates as we investigate.

## Scope

This policy covers the publisher source, GitHub Actions workflows, and deployed
static site in this repository. Factual corrections to episode material should
use the normal issue or feedback channels unless they expose a security risk.

## Disclosure

Please give us a reasonable opportunity to investigate and remediate a report
before publishing technical details. This project does not offer a bug bounty.
